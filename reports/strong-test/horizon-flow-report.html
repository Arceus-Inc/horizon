# Profit & profit growth by region (Q1–Q3)

## Data sources (authoritative)
- SQLite database: `warehouse.db`
- Tables / fields used:
  - `sales(region, quarter, revenue, units)` → uses `region`, `quarter`, `revenue`
  - `costs(region, quarter, cost)` → uses `region`, `quarter`, `cost`

## Definitions (so results are reproducible)
- **Quarter mapping used:** the dataset already encodes quarters directly in `sales.quarter` / `costs.quarter`.
  - **Q1** = rows where `quarter = 'Q1'`
  - **Q2** = rows where `quarter = 'Q2'`
  - **Q3** = rows where `quarter = 'Q3'`
  - (No month/date field exists in this dataset; quarter is the time period column.)
- **Profit formula (by region, quarter):**
  - `profit = SUM(revenue) - SUM(cost)`
  - implemented as a join on `(region, quarter)` and computed as `SUM(s.revenue - c.cost)`.
- **Profit growth (quarter-over-quarter, by region):**
  - `QoQ growth Q2 vs Q1 = profit(Q2) - profit(Q1)`
  - `QoQ growth Q3 vs Q2 = profit(Q3) - profit(Q2)`

## Results (computed from `warehouse.db`)
All values are in the same currency units as `sales.revenue` / `costs.cost`.

| Region | Q1 profit | Q2 profit | Q3 profit | Growth (Q2−Q1) | Growth (Q3−Q2) |
|---|---:|---:|---:|---:|---:|
| A | 300 | 400 | 600 | 100 | 200 |
| B | 150 | 200 | 300 | 50 | 100 |
| C | 100 | 180 | 90 | 80 | -90 |

## How to verify
Run:
```bash
python verify.py
```
`verify.py` recomputes profit and growth from `warehouse.db` and exits non-zero if any reported value differs beyond a small tolerance.

import sqlite3
import sys

TOL = 1e-9

EXPECTED = {
    # region: {quarter: profit}
    "A": {"Q1": 300.0, "Q2": 400.0, "Q3": 600.0},
    "B": {"Q1": 150.0, "Q2": 200.0, "Q3": 300.0},
    "C": {"Q1": 100.0, "Q2": 180.0, "Q3": 90.0},
}

EXPECTED_GROWTH = {
    # region: {growth_label: delta_profit}
    "A": {"Q2_vs_Q1": 100.0, "Q3_vs_Q2": 200.0},
    "B": {"Q2_vs_Q1": 50.0, "Q3_vs_Q2": 100.0},
    "C": {"Q2_vs_Q1": 80.0, "Q3_vs_Q2": -90.0},
}


def main() -> int:
    con = sqlite3.connect("warehouse.db")
    cur = con.cursor()

    # Profit formula: revenue - cost, joined on (region, quarter)
    cur.execute(
        """
        SELECT s.region, s.quarter, SUM(s.revenue - c.cost) AS profit
        FROM sales s
        JOIN costs c
          ON s.region = c.region
         AND s.quarter = c.quarter
        WHERE s.quarter IN ('Q1','Q2','Q3')
        GROUP BY s.region, s.quarter
        ORDER BY s.region, s.quarter;
        """
    )

    got = {}
    for region, quarter, profit in cur.fetchall():
        got.setdefault(region, {})[quarter] = float(profit)

    errors = []

    # Check profits
    for region, qmap in EXPECTED.items():
        for quarter, exp in qmap.items():
            act = got.get(region, {}).get(quarter, None)
            if act is None or abs(act - exp) > TOL:
                errors.append(f"profit mismatch: region={region} quarter={quarter} expected={exp} actual={act}")

    # Compute growths (delta)
    for region in EXPECTED:
        q1 = got[region]["Q1"]
        q2 = got[region]["Q2"]
        q3 = got[region]["Q3"]
        g21 = q2 - q1
        g32 = q3 - q2
        for label, exp in EXPECTED_GROWTH[region].items():
            act = {"Q2_vs_Q1": g21, "Q3_vs_Q2": g32}[label]
            if abs(act - exp) > TOL:
                errors.append(f"growth mismatch: region={region} {label} expected={exp} actual={act}")

    con.close()

    if errors:
        for e in errors:
            print(e, file=sys.stderr)
        return 1

    print("verify.py: OK")
    return 0


if __name__ == "__main__":
    raise SystemExit(main())

- Join key: `(region, quarter)`

**Scope / filters**
- Regions: all regions present in joined data (**A, B, C**)
- Time window: all quarters present in the warehouse (**Q1–Q3**)

---

## 2) Metric definitions (explicit formulas + units)

### 2.1 Cost-to-profit efficiency metric (used for ranking)

I used **profit per $ invested** as the efficiency metric:

- **Efficiency (profit_per_$)** = `total_profit / total_investment`
- In this dataset, **total_investment = total_cost = SUM(costs.cost)**.

So, per region:

- `total_investment_r = SUM(costs.cost)`  
- `total_profit_r = SUM(sales.revenue - costs.cost)`  
- **`profit_per_$_r = total_profit_r / total_investment_r`**

**Units:** dollars of profit per 1 dollar of investment (e.g., `0.54` means ~$0.54 profit per $1 invested).

### 2.2 Reallocation scenario ROI metric (explicit equation)

For the spend shift scenario, I report **estimated incremental ROI** as:

- **estimated_incremental_ROI** = `estimated_incremental_profit / amount_shifted`

Where:
- `amount_shifted` is the dollars of investment moved from a source region to a destination region.
- `estimated_incremental_profit` is computed using the efficiency differences (see scenario below).

**Units:** dollars of incremental profit per 1 dollar shifted.

import sqlite3

def compute(db_path='warehouse.db', shift_amount=100.0, sensitivity=0.10):
    con = sqlite3.connect(db_path)
    cur = con.cursor()

    # Region-level aggregation across all available quarters (Q1-Q3 in this warehouse)
    cur.execute('''WITH joined AS (
      SELECT s.region, s.quarter, c.cost, (s.revenue - c.cost) AS profit
      FROM sales s
      JOIN costs c USING(region, quarter)
    )
    SELECT region,
           SUM(cost) AS total_cost,
           SUM(profit) AS total_profit,
           1.0*SUM(profit)/SUM(cost) AS efficiency
    FROM joined
    GROUP BY region
    ORDER BY region;''')
    region_rows = cur.fetchall()

    eff = {r: e for (r, _c, _p, e) in region_rows}
    least_region = min(eff, key=eff.get)
    most_region = max(eff, key=eff.get)

    base_diff = eff[most_region] - eff[least_region]
    base_incremental_profit = shift_amount * base_diff
    base_incremental_roi = base_incremental_profit / shift_amount

    # Sensitivity: pessimistic case where destination efficiency is lower and source efficiency is higher
    eff_dest_adj = eff[most_region] * (1 - sensitivity)
    eff_src_adj = eff[least_region] * (1 + sensitivity)
    sens_diff = eff_dest_adj - eff_src_adj
    sens_incremental_profit = shift_amount * sens_diff
    sens_incremental_roi = sens_incremental_profit / shift_amount

    return {
        'region_rows': region_rows,
        'most_region': most_region,
        'least_region': least_region,
        'shift_amount': shift_amount,
        'base_incremental_profit': base_incremental_profit,
        'base_incremental_roi': base_incremental_roi,
        'sensitivity': sensitivity,
        'sens_incremental_profit': sens_incremental_profit,
        'sens_incremental_roi': sens_incremental_roi,
    }

if __name__ == '__main__':

def compute_region_metrics(db_path: str = 'warehouse.db'):
    con = sqlite3.connect(db_path)
    cur = con.cursor()
    rows = cur.execute(
        """
        WITH joined AS (
          SELECT s.region, s.quarter, c.cost AS cost, (s.revenue - c.cost) AS profit
          FROM sales s
          JOIN costs c USING(region, quarter)
        )
        SELECT region,
               SUM(cost) AS total_cost,
               SUM(profit) AS total_profit,
               1.0*SUM(profit)/SUM(cost) AS profit_per_cost,
               CASE WHEN SUM(profit)=0 THEN NULL ELSE 1.0*SUM(cost)/SUM(profit) END AS cost_per_profit
        FROM joined
        GROUP BY region
        ORDER BY region;
        """
    ).fetchall()
    out = {}
    for r, c, p, ppc, cpp in rows:
        out[r] = {
            'cost': float(c),
            'profit': float(p),
            'profit_per_cost': float(ppc),
            'cost_per_profit': None if cpp is None else float(cpp),
        }
    return out

def compute_plan_expected_incremental_profit(region_metrics: dict, plan_rows: list[tuple[str,str,float]]):

    tot = 0.0
    for fr, to, amt in plan_rows:
        tot += amt * (region_metrics[to]['profit_per_cost'] - region_metrics[fr]['profit_per_cost'])
    return tot

# Profit-efficiency by region & quarter (with robustness)

## Data source & grain
- **Source**: local SQLite warehouse `warehouse.db`
  - Tables queried: `sales(region, quarter, revenue, units)` and `costs(region, quarter, cost)`
  - Query grain used throughout: **region × quarter** via `sales JOIN costs USING(region, quarter)`.
- **Coverage in this warehouse**: 3 regions (A,B,C) × 3 quarters (Q1–Q3) = **9 joined rows**.

## Metric definitions (exact)
### Profit
- **Numerator inputs**: `sales.revenue` and `costs.cost`
- **Definition**: `profit = revenue - cost`
- **Unit**: currency units (same unit as `revenue`/`cost` in the tables)
- **Aggregation level**: region×quarter row (already aggregated in source tables)

### Profit efficiency (primary metric)
- **Definition**: 
  - `profit_efficiency = profit / cost = (revenue - cost) / cost`
- **Interpretation / unit**: **profit per $1 of cost** (dimensionless ratio; e.g., 0.50 = $0.50 profit per $1 cost)
- **Aggregation level**: computed per **region×quarter** row.

### Quarter definition
- The warehouse provides a `quarter` **label** column with values **Q1, Q2, Q3**. This analysis treats those labels as the quarter definition (no date-based re-bucketing was possible because no date column exists).

## Profit efficiency by region and quarter (with row counts)
Row count per cell is **1** (one joined row per region×quarter). I also report `units` as an additional exposure-like count.

Uncertainty: because there is only one aggregated record per cell, I report an **approximate 95% CI** using a **Poisson variance** approximation on totals:
- assume `Var(revenue)≈revenue`, `Var(cost)≈cost` ⇒ `Var(profit)=Var(revenue-cost)≈revenue+cost`
- `SE(profit_efficiency) ≈ sqrt(revenue+cost)/cost`

def spearman_rank_corr(order1, order2):
    # orders are lists of region labels best->worst
    r1={r:i+1 for i,r in enumerate(order1)}
    r2={r:i+1 for i,r in enumerate(order2)}
    regions=sorted(r1.keys())
    xs=[r1[r] for r in regions]
    ys=[r2[r] for r in regions]
    mx=sum(xs)/len(xs); my=sum(ys)/len(ys)
    num=sum((x-mx)*(y-my) for x,y in zip(xs,ys))
    den=math.sqrt(sum((x-mx)**2 for x in xs)*sum((y-my)**2 for y in ys))
    return num/den if den else float('nan')

def eff_ci(revenue,cost,z=1.96):
    profit=revenue-cost
    eff=profit/cost
    var_profit=revenue+cost  # Poisson approx
    se=math.sqrt(var_profit)/cost
    return eff,se,eff-z*se,eff+z*se
