# Profit by region (Q1–Q3)

## Profit definition
**Profit formula used:** `profit = revenue - cost`.

**Source tables/columns (from `warehouse.db`):**
- `sales.region`, `sales.quarter`, `sales.revenue` (and `sales.units` for sanity-check context)
- `costs.region`, `costs.quarter`, `costs.cost`

Profit is computed at the joined row level as `(sales.revenue - costs.cost)` and then aggregated (SUM) by `region, quarter`.

## Quarter / time-dimension (requirement)
There is **no date column** available in the warehouse tables; the only time dimension present is the `quarter` field.

Schema excerpts (evidence):

```sql
PRAGMA table_info(sales);
```
Columns returned:
- `region` (TEXT)
- `quarter` (TEXT)
- `revenue` (INTEGER)
- `units` (INTEGER)

```sql
PRAGMA table_info(costs);
```
Columns returned:
- `region` (TEXT)
- `quarter` (TEXT)
- `cost` (INTEGER)

Therefore, Q1–Q3 are taken directly from `sales.quarter` / `costs.quarter` with `quarter IN ('Q1','Q2','Q3')`.

## Reproducible query (evidence)
This SQL reproduces the region-quarter revenue/cost/profit totals and row counts used below:

```sql
WITH joined AS (
  SELECT s.region,
         s.quarter,
         s.revenue,
         c.cost,
         (s.revenue - c.cost) AS profit,
         s.units
  FROM sales s
  JOIN costs c
    ON s.region = c.region
   AND s.quarter = c.quarter
  WHERE s.quarter IN ('Q1','Q2','Q3')
)
SELECT region,
       quarter,
       SUM(revenue) AS revenue,
       SUM(cost) AS cost,
       SUM(profit) AS profit,
       SUM(units) AS units,
       COUNT(*) AS rows
FROM joined
GROUP BY region, quarter
ORDER BY region,
         CASE quarter WHEN 'Q1' THEN 1 WHEN 'Q2' THEN 2 WHEN 'Q3' THEN 3 ELSE 99 END;
```

Warehouse sanity-check counts:
- `sales`: 9 rows total; 3 regions; quarters present = Q1,Q2,Q3
- `costs`: 9 rows total; 3 regions; quarters present = Q1,Q2,Q3

# Profit growth by region

## Growth definition
For each region and quarter transition:
- **Q2 vs Q1 growth** = `(profit_Q2 - profit_Q1) / profit_Q1`
- **Q3 vs Q2 growth** = `(profit_Q3 - profit_Q2) / profit_Q2`

## Computed growth values

| region | growth period | profit_t-1 | profit_t | growth |
|---|---|---:|---:|---:|
| A | Q2 vs Q1 | 300 | 400 | 0.3333333333 |
| A | Q3 vs Q2 | 400 | 600 | 0.5 |
| B | Q2 vs Q1 | 150 | 200 | 0.3333333333 |
| B | Q3 vs Q2 | 200 | 300 | 0.5 |
| C | Q2 vs Q1 | 100 | 180 | 0.8 |
| C | Q3 vs Q2 | 180 | 90 | -0.5 |

Reproducible SQL to compute the growth table above (window function over region-ordered quarters):

```sql
WITH rq AS (
  SELECT s.region,
         s.quarter,
         SUM(s.revenue - c.cost) AS profit
  FROM sales s
  JOIN costs c
    ON s.region = c.region
   AND s.quarter = c.quarter
  WHERE s.quarter IN ('Q1','Q2','Q3')
  GROUP BY s.region, s.quarter
), ordered AS (
  SELECT region,
         quarter,
         profit,
         LAG(profit) OVER (
           PARTITION BY region
           ORDER BY CASE quarter WHEN 'Q1' THEN 1 WHEN 'Q2' THEN 2 WHEN 'Q3' THEN 3 ELSE 99 END
         ) AS profit_prev
  FROM rq
)
SELECT region,
       quarter,
       profit_prev,
       profit,
       (profit - profit_prev) * 1.0 / profit_prev AS growth_vs_prev
FROM ordered
WHERE quarter IN ('Q2','Q3')
ORDER BY region,
         CASE quarter WHEN 'Q2' THEN 2 WHEN 'Q3' THEN 3 ELSE 99 END;
```

import sqlite3

def q_order(q: str) -> int:
    return {"Q1": 1, "Q2": 2, "Q3": 3, "Q4": 4}.get(q, 999)

def main():
    con = sqlite3.connect("warehouse.db")
    cur = con.cursor()

    # Pull joined revenue/cost by region+quarter and compute profit.
    rows = cur.execute(
        """
        SELECT s.region,
               s.quarter,
               s.revenue,
               c.cost,
               (s.revenue - c.cost) AS profit
        FROM sales s
        JOIN costs c
          ON s.region = c.region
         AND s.quarter = c.quarter
        WHERE s.quarter IN ('Q1','Q2','Q3')
        ORDER BY s.region, s.quarter;
        """
    ).fetchall()

    # Organize by region and quarter order so growth is computed sequentially.
    by_region = {}
    for region, quarter, revenue, cost, profit in rows:
        by_region.setdefault(region, []).append(
            {
                "region": region,
                "quarter": quarter,
                "revenue": revenue,
                "cost": cost,
                "profit": profit,
            }
        )

    out_rows = []
    for region in sorted(by_region.keys()):
        items = sorted(by_region[region], key=lambda r: q_order(r["quarter"]))
        prev_profit = None
        for r in items:
            profit = r["profit"]
            if prev_profit is None:
                growth_abs = None
                growth_pct = None
            else:
                growth_abs = profit - prev_profit
                growth_pct = None if prev_profit == 0 else (profit - prev_profit) / prev_profit
            out_rows.append(
                {
                    "region": region,
                    "quarter": r["quarter"],
                    "profit": profit,
                    "profit_growth_abs": growth_abs,
                    "profit_growth_pct": growth_pct,
                }
            )
            prev_profit = profit

    # Print table (region x quarter profit and growth)
    headers = ["region", "quarter", "profit", "profit_growth_abs", "profit_growth_pct"]

    def fmt(v):
        if v is None:
            return ""
        if isinstance(v, float):
            return f"{v:.15g}"
        return str(v)

    # column widths
    widths = {h: len(h) for h in headers}
    for r in out_rows:
        for h in headers:
            widths[h] = max(widths[h], len(fmt(r[h])))

    print(" | ".join(h.ljust(widths[h]) for h in headers))
    print("-+-".join("-" * widths[h] for h in headers))
    for r in out_rows:
        print(" | ".join(fmt(r[h]).ljust(widths[h]) for h in headers))

    con.close()

if __name__ == "__main__":
    main()

# Profit = revenue - cost, in the warehouse currency units.
# Grain used for modeling and reporting: region-quarter.

ORDER = {"Q1": 1, "Q2": 2, "Q3": 3, "Q4": 4}
INV_ORDER = {v: k for k, v in ORDER.items()}


@dataclass
class Row:
    region: str
    quarter: str
    revenue: float
    cost: float
    profit: float


def _linear_regression_predict(xs: List[float], ys: List[float], x_next: float) -> Tuple[float, float, float]:
    """OLS for y = a + b*x. Returns (y_hat_next, intercept, slope)."""
    n = len(xs)
    mx = sum(xs) / n
    my = sum(ys) / n
    sxx = sum((x - mx) ** 2 for x in xs)
    sxy = sum((x - mx) * (y - my) for x, y in zip(xs, ys))
    slope = 0.0 if sxx == 0 else sxy / sxx
    intercept = my - slope * mx
    return intercept + slope * x_next, intercept, slope


def _fetch_region_quarter_profit(db_path: str = "warehouse.db") -> Tuple[List[Row], Dict[str, str]]:
    con = sqlite3.connect(db_path)
    cur = con.cursor()

    # Find available quarter labels in the joined sales/costs data
    qrows = cur.execute(
        """
        SELECT DISTINCT s.quarter
        FROM sales s
        JOIN costs c
          ON s.region = c.region AND s.quarter = c.quarter
        """
    ).fetchall()
    quarters = sorted([r[0] for r in qrows], key=lambda q: ORDER.get(q, 999))
    if len(quarters) < 2:
        raise RuntimeError(f"Need at least 2 quarters to fit a trend; found {quarters}")

    # Use last quarter as baseline; next quarter is the next label if present, else derive (Q4 if last=Q3, etc.)
    last_q = quarters[-1]
    last_qi = ORDER.get(last_q)
    if last_qi is None:
        raise RuntimeError(f"Unrecognized last quarter label: {last_q}")

    next_qi = last_qi + 1
    next_q = INV_ORDER.get(next_qi, f"Q{next_qi}")

    rows = cur.execute(
        """
        SELECT s.region,
               s.quarter,
               CAST(s.revenue AS REAL) AS revenue,
               CAST(c.cost AS REAL) AS cost,
               CAST(s.revenue AS REAL) - CAST(c.cost AS REAL) AS profit
        FROM sales s
        JOIN costs c
          ON s.region = c.region
         AND s.quarter = c.quarter
        ORDER BY s.region, s.quarter;
        """
    ).fetchall()
    con.close()

    out = [Row(region=r[0], quarter=r[1], revenue=float(r[2]), cost=float(r[3]), profit=float(r[4])) for r in rows]
    meta = {
        "history_quarters": ",".join(quarters),
        "last_quarter": last_q,
        "next_quarter": next_q,
    }
    return out, meta


def compute_projections(lookback_quarters: int = 3) -> Tuple[List[dict], Dict[str, str]]:
    rows, meta = _fetch_region_quarter_profit()

    # group by region
    by_region: Dict[str, List[Row]] = {}
    for r in rows:
        by_region.setdefault(r.region, []).append(r)

    last_q = meta["last_quarter"]
    next_q = meta["next_quarter"]

    results: List[dict] = []
    for region in sorted(by_region.keys()):
        items = sorted(by_region[region], key=lambda rr: ORDER.get(rr.quarter, 999))

        # Keep only rows with recognized quarter labels (Q1..Q4)
        items = [rr for rr in items if rr.quarter in ORDER]
        if len(items) < 2:
            raise RuntimeError(f"Region {region}: need at least 2 quarters to project")

        # Identify last quarter actual profit
        last_items = [rr for rr in items if rr.quarter == last_q]
        if not last_items:
            raise RuntimeError(f"Region {region}: missing last quarter ({last_q})")
        last_quarter_profit = float(last_items[-1].profit)

        # Lookback window (use min(lookback_quarters, available))
        window = items[-min(lookback_quarters, len(items)) :]
        xs = [float(ORDER[rr.quarter]) for rr in window]
        ys = [float(rr.profit) for rr in window]
        n = len(xs)

        yhat_next, intercept, slope = _linear_regression_predict(xs, ys, float(ORDER.get(next_q, ORDER[last_q] + 1)))

        # incremental opportunity definition per prompt
        incremental = yhat_next - last_quarter_profit

        results.append(
            {
                "region": region,
                "last_quarter_profit": last_quarter_profit,
                "projected_next_quarter_profit": yhat_next,
                "incremental_profit_opportunity": incremental,
                "model": "linear_regression_profit_vs_quarter_index",
                "n_quarters": n,
                "slope_per_quarter": slope,
                "intercept": intercept,
                "units": "profit (warehouse currency units)",
                "last_quarter": last_q,
                "next_quarter": next_q,
                "history_quarters": meta["history_quarters"],
            }
        )

    return results, meta

def _draw_line(pixels, x0, y0, x1, y1, color):
    # Bresenham
    w = len(pixels[0])
    h = len(pixels)
    dx = abs(x1 - x0)
    dy = -abs(y1 - y0)
    sx = 1 if x0 < x1 else -1
    sy = 1 if y0 < y1 else -1
    err = dx + dy
    x, y = x0, y0
    while True:
        if 0 <= x < w and 0 <= y < h:
            pixels[y][x] = color
        if x == x1 and y == y1:
            break
        e2 = 2 * err
        if e2 >= dy:
            err += dy
            x += sx
        if e2 <= dx:
            err += dx
            y += sy

## Metric definitions (used for every region)
- **Price per unit**: `price_per_unit = revenue / units`
- **Cost per unit (CPU)**: `cost_per_unit = cost / units`
- **Profit** (required definition): `profit = (price_per_unit - cost_per_unit) * units`

## Periods
- `period_start = Q1`
- `period_end = Q3`

## Decomposition formula (two-period midpoint / Shapley-style; reconciles exactly)
Let `U` = units, `P` = price_per_unit, `C` = cost_per_unit, `M = (P - C)`.

For each region, profit change is decomposed as:

- `Δprofit_price = (P_end - P_start) * avg(U)`
- `Δprofit_volume = (U_end - U_start) * avg(M)`
- `Δprofit_cost_per_unit = -(C_end - C_start) * avg(U)`

- `avg(U) = (U_start + U_end) / 2`
- `avg(M) = (M_start + M_end) / 2`

def _fit_simple_linear_regression(xs: List[float], ys: List[float]) -> Tuple[float, float, float]:
    """Returns (intercept, slope, rmse)."""
    n = len(xs)
    if n < 2:
        raise ValueError("Need >=2 points")

    xbar = sum(xs) / n
    ybar = sum(ys) / n
    sxx = sum((x - xbar) ** 2 for x in xs)
    if sxx == 0:
        slope = 0.0
    else:
        sxy = sum((x - xbar) * (y - ybar) for x, y in zip(xs, ys))
        slope = sxy / sxx
    intercept = ybar - slope * xbar

    preds = [intercept + slope * x for x in xs]
    rmse = math.sqrt(sum((y - p) ** 2 for y, p in zip(ys, preds)) / n)
    return intercept, slope, rmse


def _median(values: List[float]) -> float:
    s = sorted(values)
    n = len(s)
    if n == 0:

    mid = n // 2

def _winsorize(values: List[float], p: float) -> List[float]:
    assert 0 <= p < 0.5
    s = sorted(values)
    n = len(s)
    lo_i = int(math.floor(p * n))
    hi_i = int(math.ceil((1 - p) * n)) - 1
    lo = s[max(0, min(n - 1, lo_i))]
    hi = s[max(0, min(n - 1, hi_i))]

    xs=[x for x,y in xy]; ys=[y for x,y in xy]

def ols_predict(xs: List[float], ys: List[float], x_next: float) -> Tuple[float, float, float]:
    n = len(xs)
    if n < 2:
        raise ValueError("Need at least 2 points")
    xbar = sum(xs) / n
    ybar = sum(ys) / n
    sxx = sum((x - xbar) ** 2 for x in xs)
    if sxx == 0:
        b = 0.0
    else:
        sxy = sum((x - xbar) * (y - ybar) for x, y in zip(xs, ys))
        b = sxy / sxx
    a = ybar - b * xbar
    yhat = a + b * x_next
    return yhat, a, b


def ridge_predict(xs: List[float], ys: List[float], x_next: float, lam: float) -> Tuple[float, float, float]:
    n = len(xs)
    if n < 2:
        raise ValueError("Need at least 2 points")
    xbar = sum(xs) / n
    ybar = sum(ys) / n
    sxx = sum((x - xbar) ** 2 for x in xs)
    sxy = sum((x - xbar) * (y - ybar) for x, y in zip(xs, ys))
    b = 0.0 if (sxx + lam) == 0 else sxy / (sxx + lam)
    a = ybar - b * xbar
    yhat = a + b * x_next
    return yhat, a, b


def median_slope_predict(xs: List[float], ys: List[float], x_next: float) -> Tuple[float, float, float]:
    n = len(xs)
    if n < 2:
        raise ValueError("Need at least 2 points")
    slopes = []
    for i in range(n):
        for j in range(i + 1, n):
            dx = xs[j] - xs[i]
            if dx != 0:
                slopes.append((ys[j] - ys[i]) / dx)
    slopes.sort()
    b = slopes[len(slopes) // 2] if slopes else 0.0
    intercepts = [y - b * x for x, y in zip(xs, ys)]
    intercepts.sort()
    a = intercepts[len(intercepts) // 2]
    yhat = a + b * x_next
    return yhat, a, b

def _predict_with_transform(spec: Dict, xs: List[float], ys: List[float], x_next: float) -> Tuple[float, float, float]:
    transform = spec.get("target_transform", "none")
    model = spec["model"]
    lam = float(spec.get("lam", 0.0))

    if transform == "none":
        ys_t = ys
        inv = lambda v: v
    elif transform == "log1p":
        ys_t = [math.log1p(max(y, -0.999999999)) for y in ys]
        inv = lambda v: math.expm1(v)
    else:
        raise ValueError("Unknown target_transform")

    elif model == "mean":

def ols_slope_intercept(xs: List[float], ys: List[float]) -> Tuple[float, float]:
    n = len(xs)
    xbar = sum(xs) / n
    ybar = sum(ys) / n
    sxx = sum((x - xbar) ** 2 for x in xs)
    if sxx == 0:
        return 0.0, ybar
    sxy = sum((x - xbar) * (y - ybar) for x, y in zip(xs, ys))
    b1 = sxy / sxx
    b0 = ybar - b1 * xbar
    return b1, b0

def ols_slope_intercept(x: List[float], y: List[float]) -> Tuple[float, float]:
    n = len(x)
    x_bar = sum(x) / n
    y_bar = sum(y) / n
    sxx = sum((xi - x_bar) ** 2 for xi in x)
    sxy = sum((xi - x_bar) * (yi - y_bar) for xi, yi in zip(x, y))
    m = sxy / sxx if sxx != 0 else 0.0
    b = y_bar - m * x_bar
    return m, b


def ridge_slope_intercept(x: List[float], y: List[float], lam: float) -> Tuple[float, float]:

    sumy = sum(y)
    sumxy = sum(xi * yi for xi, yi in zip(x, y))

    a21 = sumx
